# 🎨 ArtSphere - Art Gallery Frontend

ArtSphere is a modern full-stack Art Gallery web application where users can explore, purchase, and favorite artworks, artists can upload and manage their art collections, and administrators can manage the entire platform. The application provides a responsive UI, secure authentication, role-based dashboards, and an interactive user experience.

---

## 🌐 Live Website

🔗 https://art-gallery-85d90.web.app/

---

## 📌 Project Overview

ArtSphere is designed to connect art lovers with talented artists. Users can browse artworks, purchase digital art, participate in auctions, and manage their personal collections. The platform supports three user roles:

- 👤 User
- 🎨 Artist
- 🛡️ Admin

Each role has its own dedicated dashboard and permissions.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Farjana02mim/Art-Gallery-Client.git
```

Go to project directory

```bash
cd art-gallery-client
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

---

## 🔑 Environment Variables
